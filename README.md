# Счёт РФ — schetrf.github.io

Одностраничный статический сайт сервиса «Счёт РФ»: счёт в цифровых рублях для тех, кто приехал в Российскую Федерацию, — для оплаты расходов и получения доходов на время пребывания в стране.

- Владелец: Владимир Яковлев
- Адрес: https://schetrf.github.io
- Стек: чистый HTML + CSS + немного vanilla JS. Без сборки и зависимостей.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг (RU по умолчанию, EN через переключатель) |
| `styles.css` | Стили, mobile-first |
| `script.js` | Переключение языка, мобильное меню, форма заявки |
| `favicon.svg` | Логотип / иконка |
| `og-image.png` | Картинка для превью ссылок (Open Graph, 1200×630) |
| `404.html` | Страница «не найдено» для GitHub Pages |
| `.nojekyll` | Отключает Jekyll на GitHub Pages |

## Языки

Русский текст — исходный в HTML. Английский перевод хранится в data-атрибутах:
`data-en` (текст), `data-en-placeholder`, `data-en-aria-label`. Выбор сохраняется в `localStorage`,
также можно открыть `?lang=en`.

## Форма

Форма **ничего не отправляет на сервер**. После проверки полей показывается сообщение «Спасибо»,
открывается почтовый клиент (`mailto:`) с подготовленным текстом и предлагаются кнопки Telegram/email.
Для реального приёма заявок позже можно подключить, например, Formspree или Telegram-бота.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Создать репозиторий `schetrf.github.io` в аккаунте/организации `schetrf`.
2. `git remote add origin git@github.com:schetrf/schetrf.github.io.git && git push -u origin main`
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.

## Важно

Сайт носит информационный характер. На сайте намеренно нет цен, названий банков-партнёров, статистики,
отзывов и лицензий — добавляйте их только при наличии подтверждённых данных.

## Демо личного кабинета (прототип, без бэкенда)

- `index.html` — кнопка «Войти» в шапке и блок «Личный кабинет · ДЕМО» в hero. Вход по телефону (+7, маска) и SMS-коду; **SMS не отправляется, демо-код всегда `1234`**. Сессия хранится в `localStorage` (`schetrf-demo-session`). Логика — `login.js`.
- `cabinet.html` (+ `cabinet.css`, `cabinet.js`) — кликабельный прототип: профиль вымышленного пользователя, миграционный учёт (дата окончания = сегодня + 25 дней, считается в JS; цвета: зелёный > 30, жёлтый ≤ 30, красный ≤ 7 дней; ссылка «Демо: регистрация истекла» показывает обязательную форму рейса/билета), баланс и пополнение (демо), выписка (Дата / Описание / Дебет / Кредит / Остаток), карточка паспорта с водяным знаком «ОБРАЗЕЦ / ДЕМО — не является документом» и QR-кодом, список органов регистрации с источниками.
- «Перевести» (кнопка у баланса, плитка и пункт навигации «Перевод») — демо межбанковского перевода: по номеру телефона (выбор банка), по номеру карты (16–19 цифр, маска, проверка Луна), по реквизитам (ФИО, БИК 9 цифр, счёт 20 цифр, назначение). Комиссия 0 ₽ (демо), шаг подтверждения, демо-код 1234, экран успеха. Списание уменьшает демо-баланс (не ниже нуля) и добавляет строку в выписку. **Деньги никуда не отправляются.**
- Без сессии `cabinet.html` перенаправляет на `index.html#login`. «Сбросить демо-данные» очищает пополнения, флаг истёкшей регистрации и данные билета.
- Все данные персоны вымышлены; аватар — иллюстрация (`cabinet-assets/avatar.svg`), не фото реального человека.
- QR-код — статический SVG, сгенерированный при сборке: `pip install segno && python3 tools/make_passport_qr.py` → `cabinet-assets/passport-qr.svg`. Внешних зависимостей во время работы нет.
- Данные органов регистрации (`OFFICES` в `cabinet.js`) взяты из официальных источников (mos.ru) по состоянию на октябрь 2026 г.; непроверенные телефоны/часы не указаны. Перед показом клиентам проверяйте актуальность.
